# Activity Monitor - Build Plan

## Overview

A Hammerspoon-based tool that automatically tracks what you're working on throughout the day by monitoring active application windows. It logs activity, supports manual log entries via a hotkey-triggered webview dialog, and generates end-of-day markdown summaries using the Claude CLI.

## Architecture

### Files

```
activity-monitor/
├── hammerspoon/
│   ├── activity_monitor.lua      # Main entry point, loaded via dofile from ~/.hammerspoon/init.lua
│   ├── config.lua                # User-editable configuration
│   ├── activity_tracker.lua      # Event-driven + polling fallback, writes to daily log
│   ├── activity_logger.lua       # Webview dialog for manual log entries (hotkey-triggered)
│   └── activity_summary.lua      # Generates daily summary via Claude CLI
├── logs/                         # Daily activity logs (e.g., 2026-03-06.md)
├── summaries/                    # Daily summaries (e.g., 2026-03-06.md)
├── instructions.md               # Custom instructions for summary generation
├── README.md
└── PLAN.md
```

### Components

#### 1. Activity Tracker (`activity_tracker.lua`)
- **Primary: Event-driven** via `hs.window.filter`
  - `windowFocused` — fires when switching apps or windows
  - `windowTitleChanged` — fires when a window title changes (e.g., switching browser tabs)
- **Fallback: Configurable polling timer** (default 30s) to catch anything missed by events
  - Interval configurable via `config.polling_interval`
- Captures: active application name, window title, timestamp
- Deduplicates — only logs when the app+title actually changes from the last entry
- Appends entries to the daily log file under a `## Tracked Activity` section
- Log format: `- [HH:MM:SS] AppName - Window Title`

#### 2. Manual Logger (`activity_logger.lua`)
- Triggered by a configurable hotkey (default: `Ctrl+Shift+L`)
- Opens a webview modal dialog for typing a manual log entry
- Entries are appended to the daily log file under a `## Manual Entries` section
- Supports multi-line text input
- Dialog includes a submit button and cancel/close

#### 3. Summary Generator (`activity_summary.lua`)
- Triggered manually by hotkey (default: `Ctrl+Shift+S`)
- Triggered automatically on a schedule (default: 5:30 PM on weekdays, configurable)
- Reads the daily log file and `instructions.md`
- Pipes both to the Claude CLI to generate a markdown summary
- Saves the summary to `summaries/YYYY-MM-DD.md`
- Shows a notification when summary generation is complete

#### 4. Main Entry Point (`activity_monitor.lua`)
- Requires and initializes all components
- Sets up hotkeys
- Starts the window filter and fallback polling timer
- Provides a menu bar icon for status/controls (start, stop, generate summary, open log)

### Configuration

All settings are configurable in `activity_monitor.lua`:

Stored in a separate `config.lua` file for easy editing:

```lua
return {
    polling_interval = 30,           -- fallback polling interval in seconds
    log_hotkey_mods = {"ctrl", "shift"},
    log_hotkey_key = "L",
    summary_hotkey_mods = {"ctrl", "shift"},
    summary_hotkey_key = "S",
    auto_summary_enabled = true,     -- generate summary automatically
    auto_summary_time = "17:30",     -- time to auto-generate (24h format)
    auto_summary_days = {2,3,4,5,6}, -- days of week (1=Sun, 2=Mon, ..., 7=Sat)
    base_path = os.getenv("HOME") .. "/Projects/activity-monitor",
}
```

### Daily Log Format (`logs/YYYY-MM-DD.md`)

```markdown
# Activity Log - 2026-03-06

## Tracked Activity
- [09:00:15] VS Code - activity-monitor/init.lua
- [09:05:45] Chrome - GitHub Pull Request #123
- [09:12:00] Terminal - zsh: npm test
- [09:15:30] VS Code - activity-monitor/tracker.lua

## Manual Entries
- [10:30:00] Discussed API design with team in standup, decided on REST over GraphQL
- [14:00:00] Took a walk, thought through the caching strategy
```

### Summary Format (`summaries/YYYY-MM-DD.md`)

Generated by Claude CLI — a concise markdown summary of the day's work, guided by the custom instructions.

### Custom Instructions (`instructions.md`)

User-editable file that gets included in the Claude CLI prompt. Example content:

```markdown
- Ignore Netflix, YouTube, and Spotify activity — this is background music/entertainment
- Group related activities together (e.g., all work on the same project)
- Highlight context switches between different projects
- Note time spent in meetings or communication tools
- Keep the summary concise but capture all meaningful work
```

## Hotkeys

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+L` | Open manual log entry dialog |
| `Ctrl+Shift+S` | Generate summary for today |

## Integration

Add to `~/.hammerspoon/init.lua`:
```lua
dofile(os.getenv("HOME") .. "/Projects/activity-monitor/hammerspoon/activity_monitor.lua")
```

## Dependencies

- Hammerspoon (installed)
- Claude CLI (`claude` command available in PATH)
